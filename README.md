## Data Visualization and Reporting in Agribusiness

This project is part of my Agribusiness Data Analytics Internship – Week 2 task.

### Project Objective

The objective of this project is to visualize and analyze agricultural production data using appropriate charts and tables. The analysis focuses on identifying production trends, comparing different crops, and presenting important insights in a simple and understandable format.

### Dataset

The project uses the cleaned agribusiness dataset:

**Agribusiness_Data_Cleaning.xlsx**

### Visualizations

The report includes:

- Line Chart – Rice Production Trend (2001–02 to 2016–17)
- Column Chart – Crop Production Comparison (2016–17)
- Pie Chart – Crop-wise Production Share
- Data Table – Summary of Crop Production

### Tools Used

- Microsoft Excel
- Microsoft Word
- GitHub

### Key Crops Analyzed

- Rice
- Bajra
- Maize
- Ragi

### Files

- `Agribusiness_Data_Cleaning.xlsx` – Cleaned dataset
- `WEEK_2_Data_Visualization_Report.docx` – Final Week 2 report

## Conclusion

The visualizations make it easier to understand agricultural production trends and compare production levels among different crops. The project demonstrates the use of data visualization techniques for clear and effective agribusiness reporting.
